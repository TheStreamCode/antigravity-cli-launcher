# Support

Use [GitHub Issues](https://github.com/TheStreamCode/antigravity-cli-launcher/issues) for reproducible bugs, compatibility problems, and feature requests.

Please include:

- VS Code version
- Operating system and version
- Extension version
- The configured `antigravityCliLauncher.cliCommand` value
- Whether `agy` works in a regular VS Code integrated terminal
- Relevant terminal output, without secrets or authentication tokens

For non-public support questions, contact the maintainer at `info@mikesoft.it` or through [mikesoft.it](https://mikesoft.it).

Report security vulnerabilities through the private process described in `SECURITY.md`, not through Issues or support requests.

This project is maintained independently and cannot provide official Google or Antigravity account support.
